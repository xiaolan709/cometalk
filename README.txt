Come Talk HTML/CSS 原型

檔案：
- index.html：五個主要介面的 HTML 結構
- style.css：視覺樣式與響應式版面
- script.js：頁面切換、3D 風格島嶼的簡單互動、聊天示意、任務與紀錄篩選

如何開啟：
1. 將三個檔案放在同一個資料夾。
2. 直接雙擊 index.html，用 Chrome 或 Edge 開啟。
3. 若要編輯，推薦使用 Visual Studio Code。

注意：
- 這是前端原型，聊天回覆是本機示意邏輯，並未連接真正的 AI API。
- 3D 小島是使用 CSS 製作的 2.5D 視覺示意，不是真正的 3D 模型。
- 資料目前不會寫入資料庫，重新整理頁面後，互動狀態會重設。
- Google Fonts 需要網路連線；若無法載入，會使用系統中文字型。
